# Dhruv Chaudhary — Portfolio

A static site: plain HTML, CSS and JavaScript. No build step.

## Files
- `index.html` — the page
- `projects.js` — your projects (edit this to update the Projects section)
- `main.js` — theme toggle, animations, header highlight and project cards

## Deploy on Vercel
1. Put these files in a new GitHub repository (all at the top level).
2. On vercel.com, choose **Add New → Project**, import the repository and click **Deploy**.
   Leave Framework Preset as **Other**; no build command or output directory is needed.

Every push to the repository redeploys the site automatically.

## Update your projects
Open `projects.js`, edit or add a project (instructions are at the top of the file), then commit and push.
Only people with access to your GitHub repo can change the site.

## Preview locally
Open `index.html` in a browser, or run `npx serve .` in this folder.
