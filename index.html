Featured · Query optimisation

An admin report query, from about 1.4 s to about 1 ms

Profiled slow queries with EXPLAIN ANALYZE and pg_stat_statements, then added a composite index to the report query. Partial and covering indexes turned slow auction queries into index-only scans.

30+ vulnerabilities closed after a code audit

Fixed SQL injection, shell injection, IDOR and open redirects. Replaced predictable password-reset and activation tokens with random SHA-256-hashed tokens, and moved hard-coded encryption keys into environment config.

55-second timeouts, gone

Auction cancellation and logout were hitting 55 s statement timeouts. Diagnosed database lock contention and added bounded lock timeouts with retries in PHP.

Reporting moved to ClickHouse
